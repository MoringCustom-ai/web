# 🤖 Бот клуба «Шесть месяцев»

Telegram-бот на Python (aiogram 3) для клуба «Шесть месяцев»: челлендж
**«Дофаминовый детокс · 14 дней»** с ежедневными отметками, сериями,
статистикой и мини-приложением по дизайн-макету из репозитория.

> ⚠️ Файл `Бот клуба «Шесть месяцев» — ТЗ и тексты MVP.html` — это сохранённая страница Claude Artifact: сам текст ТЗ в ней не сохранился (контент грузится во фрейме). Бот реализован по концепции, видимой в рабочем дизайн-макете `Мини-приложение «Шесть месяцев» (Copy).html`: дни челленджа, отметки ✅/🟡/❌, серии, «Я и клуб», кнопка «Открыть чат клуба». Если пришлёте полный текст ТЗ — донастрою тексты и логику под него.

## Возможности

- `/start` — приветствие и запуск челленджа (день 1 из 14 считается от старта)
- **Отметка дня** inline-кнопками: `Выдержал ✅` / `Частично 🟡` / `Сорвался ❌`
  (одна отметка на день, можно переотмечать; поддержка-реплики вместо осуждения)
- `/stats` — текущая и лучшая серия, % «выдержал», счётчики (логика серий — как в прототипе: ok продлевает, part сохраняет, fail сбрасывает)
- 🎉 Автосообщение с итогами на 14-й день
- 🔔 Ежедневное вечернее напоминание (APScheduler cron, по умолчанию 20:00 МСК; тем, кто ещё не отметил день)
- 📊 **Telegram Mini App** (`webapp/`) — дизайн-макет подключён к реальному API бота: вкладки «Мой путь» и «Клуб» строятся из отметок участников; подпись `initData` проверяется по схеме Telegram (HMAC-SHA256)
- 💾 Хранилище — SQLite (`aiosqlite`), без внешних зависимостей
- Запуск long polling (для разработки) или webhook (для продакшена)

## Структура

```
bot/
  main.py            # точка входа: бот + планировщик напоминаний
  config.py          # настройки из окружения (.env)
  storage.py         # SQLite + аналитика (серии, проценты)
  handlers/
    user.py          # команды и inline-кнопки
    keyboards.py     # тексты и клавиатуры
webapp/
  server.py          # HTTP API для мини-приложения (/api/me, /api/club) + статика
  index.html         # дизайн-макет, подключённый к API (демо-данные — fallback)
requirements.txt
.env.example
```

## Быстрый старт

```bash
pip install -r requirements.txt
cp .env.example .env        # впишите BOT_TOKEN от @BotFather
python -m bot.main          # бот (long polling)
```

Мини-приложение (нужен HTTPS-хостинг; локально можно через туннель):

```bash
python -m webapp.server     # http://0.0.0.0:3000
```

В @BotFather: `/newapp` или «Set Menu Button» → укажите URL сервера,
а в `.env` пропишите `MINI_APP_URL=https://ваш-домен` — тогда в меню бота
появится кнопка «📊 Мой путь».

## Продакшен (webhook)

```bash
WEBHOOK_URL=https://your-domain.com WEBHOOK_PORT=8443 WEBHOOK_SECRET=secret python -m bot.main
```

## Настройки (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | токен от @BotFather (обязательно) |
| `CHALLENGE_DAYS` | `14` | длительность челленджа |
| `REMINDER_HOUR/MINUTE` | `20:00` | время вечерней напоминалки |
| `TIMEZONE` | `Europe/Moscow` | таймзона напоминаний |
| `MINI_APP_URL` | — | ссылка на мини-приложение |
| `CHAT_BUTTON_URL` | — | ссылка на закрытый чат клуба |
| `DB_PATH` | `club.db` | файл SQLite |
